EasyLoop develop - Windows 공유용
=================================

1. 압축을 해제한 뒤 폴더 전체를 원하는 위치로 복사합니다.
2. EasyLoop_실행.bat를 더블클릭합니다.
3. Windows 관리자 권한 요청이 표시되면 허용합니다.
4. Windows에 192.168.30.x 주소가 없으면 사용할 주소를 입력합니다.
   - 현재 개발 PC의 기본값은 192.168.30.39입니다.
   - 다른 PC에서는 충돌하지 않는 주소를 입력해야 합니다.
   - 입력 주소는 실행 중인 Windows 세션의 로봇망/APIPA 어댑터에 적용됩니다.
5. 실행 PC의 브라우저에는 http://192.168.30.x:3000 주소가 자동으로 열립니다.
6. 같은 192.168.30.0/24 네트워크의 다른 PC에서도 콘솔에 표시된 주소로 접속합니다.

주의
----
- EasyLoop.exe와 EasyLoop_실행.bat를 반드시 같은 폴더에 두세요.
- 포트는 3000으로 고정됩니다. 기존 EasyLoop 또는 다른 프로그램이 포트 3000을 사용하면 먼저 종료하세요.
- Windows 네트워크 어댑터에 192.168.30.x 주소가 설정되어 있어야 합니다.
- 로그인 비밀번호는 파일에 적지 않고 배포 담당자에게 별도로 전달받으세요.
- Windows Defender Firewall 규칙은 EasyLoop.exe에 대해 192.168.30.0/24 원격 주소만 허용합니다.
- 종료하려면 EasyLoop 콘솔 창에서 Ctrl+C를 누르세요.
